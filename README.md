# VSequencer

Public downloads for VSequencer (Windows x64).

## Download

Get the latest version from [Releases](https://github.com/pollo-xyz/VSequencer-Releases/releases/latest).

1. Download `VSequencer_1.2.5.zip` from the release assets (not the automatic Source code archives).
2. Extract the **entire ZIP** to a folder.
3. Run `VSequencer.exe`. Keep the `_internal` folder beside the executable.

## About this repository

This repository contains release downloads and installation instructions only. The VSequencer source code and development history are maintained separately in a private repository.
